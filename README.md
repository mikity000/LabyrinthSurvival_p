# 迷宮サバイバル

## 概要
「迷宮サバイバル」は、ローグライク風のハクスラRPGです。  
プレイヤーはダンジョンを探索し、敵を倒しながら地下深くへ進んでいきます。  

主な特徴:
- **自動生成ダンジョン**: 階層ごとに構造が変化。
- **アイテムドロップ**: 敵撃破で確率でアイテム獲得、ステータスがインフレ的に上昇。
- **ゲーム進行**: HPが0になると1階層から再挑戦。ただしアイテムとステータスは引き継ぎ。
- **ランキング機能**: 到達階層を競い合う要素を実装。
- **中断・再開機能**: プレイヤーや敵のステータス・座標を保存し、同じ状況から再開可能。
- **直感的操作**: カジュアルに楽しめる操作性。

オプション画面から変更可能な設定:
- BGM・SEのON/OFF  
- ミニマップの表示/非表示  
- 地形グリッドの表示/非表示  
- ログ文字サイズ変更  

## PlayFab連携機能
- データ引継ぎ  
- 課金によるダイヤ購入  
- ゲーム内通貨でのアイテム購入  
- 到達階層ランキング  
- プレイヤーステータス保存  
- アイテムインベントリ管理  

## 開発環境
- Unity  
- Visual Studio  
- PlayFab  

## 技術的課題と学び
開発で最も苦労したのは「プレイヤーと敵のターン制御」でした。  
Unity Learn のローグライク実装を参考にしたものの、移動がブレて正常に動作しない問題が発生。解決できなかったため、一度コードを全削除して再設計しました。  

その過程で、ある開発者のブログで紹介されていた **Stateパターン** に着目し、実装を進めたところ、想定通りの動作を実現できました。  
デザインパターンの利用経験はありましたが、Stateパターンは初めてであり、非常に良い学習機会となりました。
